# Unterrichtsmaterialien

Dieses Repository enthält den Quellcode der GitHub-Pages-Website zur Bereitstellung von Unterrichtsmaterialien für die Fächer **Mathematik** und **Informatik**.

Die Website bietet eine zentrale Übersicht über öffentlich zugängliche Skripte und weitere Unterrichtsmaterialien.

**[Zur Website – Unterrichtsmaterialien](https://klw-anderegg.github.io/)**

## Inhalte

Die Unterrichtsmaterialien sind in zwei Fachbereiche gegliedert:

- **Mathematik:** Skripte und Materialien zu verschiedenen mathematischen Themen, unter anderem Analysis, Algebra, Wahrscheinlichkeit und Differentialgleichungen.
- **Informatik:** Skripte und Materialien zu verschiedenen Themen der Informatik.

Die einzelnen Materialien werden in separaten GitHub-Repositories verwaltet und über die Website verlinkt.

## Materialien herunterladen

Alle verlinkten öffentlichen Repositories sind ohne GitHub-Konto zugänglich.

Einzelne Dateien können direkt heruntergeladen werden. Für den Download eines vollständigen Repositories steht auf der jeweiligen Repository-Seite oberhalb der Dateiliste die Schaltfläche **Code → Download ZIP** zur Verfügung.

## Technische Umsetzung

Die Website wird mit **GitHub Pages** veröffentlicht und basiert auf HTML, CSS und JavaScript.

Änderungen am Quellcode werden nach einem Commit auf dem Branch `main` automatisch auf der Website veröffentlicht.

## Aktualisierungen

Die Unterrichtsmaterialien werden in den jeweiligen Repositories unabhängig von dieser Website gepflegt und bei Bedarf aktualisiert.

Eine Übersicht aller öffentlichen Repositories ist auch direkt auf [GitHub](https://github.com/KLW-Anderegg?tab=repositories) verfügbar.
